## Executed-trajectory corpus

Every arm trajectory executed in this session is logged under `{corpus_dir}` — including trajectories that never triggered a correction. `manifest.json` is a JSON list; each entry has `traj_file` (raw `(T, 3, 3)` axis-angle `.npy`), `features_file` (per-frame CSV with columns `frame, elbow_flexion, shoulder_flexion_extension, shoulder_abduction_adduction, shoulder_elevation, shoulder_internal_external_rotation`, in radians — the same features as the motion summaries), plus `goal`, `round`, `kind`, `feedback_text`, `trigger_step` (frame where discomfort was reported, or null), and `comfortable_until` (frames `[0, comfortable_until)` were executed without any discomfort report). Analyze these files with plain numpy/pandas — no repo imports are needed.

Caveats: discomfort is only reported once the violation exceeds a small tolerance (~0.02 rad), so comfortable frames may sit marginally inside the true limit — treat them as allowed poses, not exact boundary points. Treat the frames as a set of reached poses, not a time series: frame spacing is an execution artifact and dwell frames overrepresent poses in any statistic.
